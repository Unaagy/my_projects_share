файл: ddl_plus_NSI создание таблиц и заполнение справочников(одинаковый для всех вариантов)
файлы dump1 -dump4 инсерты в БД(сами данные)

Как скрафтить себе базу для своего варианта:
Выполнить скрипт ddl_plus_NSI 
Открыть новое окно SQLEditor(Редактор SQL) от схемы bd_shops
Запустить нужный dump (первая циферка в вариантах  это номер нужной базы)

Если меньше 12 ГБ оперативки, тогда инсерты выполнять по очереди
